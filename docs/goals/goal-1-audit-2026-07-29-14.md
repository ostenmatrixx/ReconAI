## Requirement gap narrowed locally

Audit 13 closed the deprecated OIDC URL-parser finding on the installed source/runtime acceptance
surface but deliberately left real post-patch identity lifecycle evidence open. The completed
boundary now adds one fresh, synthetic, loopback-only exercise:

- checksum-verified Keycloak 26.7.0 and Temurin 21.0.11+10 archives ran from an isolated temporary
  directory;
- the temporary realm retained the repository client contract while setting a 65-second access
  token, zero-reuse refresh-token rotation, and the exact loopback Back-Channel Logout endpoint;
- the actual patched web application ran with `NODE_OPTIONS=--throw-deprecation`;
- Chromium observed an authorization-code request with the fixed client, fixed callback, nonempty
  state, nonempty PKCE challenge, and `S256`, then completed login;
- the encrypted HttpOnly session was decoded only in test memory. Both access and refresh tokens
  rotated, the new expiry advanced, the browser session disclosed no provider credential, and the
  two cookie chunks remained HttpOnly and `SameSite=Lax`;
- RP-initiated logout carried the provider ID-token hint, fixed client, and fixed registered return
  URI, cleared every local session-cookie chunk, and ended the provider browser session;
- Keycloak delivered a signed Back-Channel Logout token to one real Next.js process. Replaying the
  pre-logout encrypted cookie through a distinct browser context returned only
  `reauthenticationRequired: true` and disclosed no provider credential;
- a subsequent sign-in reached the provider credential form instead of silently reusing SSO; and
- the web and provider origins still returned `200` after the lifecycle, demonstrating that fatal
  deprecation mode did not terminate the patched web process.

No raw ID token, access token, refresh token, authorization code, state value, PKCE value, session
cookie, password, client secret, or token digest is retained in the evidence artifact. The temporary
runtime used synthetic identities only and was moved to the workstation Trash after both processes
stopped and both loopback ports closed.

Existing tenant authority, database behavior, reconciliation rules, money handling, provider scope,
source-system write authority, and AI authority do not change.
