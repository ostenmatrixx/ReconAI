## Requirement gap narrowed locally

Audit 24 and the Goal 1 evidence index still listed application container execution as wholly
unverified. The first real API image build failed during its locked dependency install because the
Git-free image context ran `lefthook install`. A narrow `LEFTHOOK=0` command prefix advanced the
build and revealed the same failure in API/worker `pnpm deploy`, whose production release install
runs `prepare` again.

The corrected boundary now provides:

- a fail-closed root hook installer that honors only exact `LEFTHOOK=0` and otherwise executes
  Lefthook normally;
- one command-scoped bypass for every Git-free locked install and API/worker production deploy;
- no persisted or parameterized bypass and no disabled dependency lifecycle scripts;
- container-policy validation and focused negative tests for missing, broadened, duplicated, or
  unscoped boundaries; and
- successful builds of all three digest-pinned, non-root application images on Linux ARM64.

The first successful runtime harness then exposed a separate least-privilege defect: it projected
the complete `.env.example` into all three application containers, while API and worker both parsed
a shared full-stack schema. That run could not establish credential isolation. The accepted rerun
adds:

- exact API and worker schemas that require only their own database roles and strip unrelated
  service inputs;
- API-local and worker-local production and provider validation;
- explicit runtime environment allowlists for web, API, and worker; and
- live-container rejection of peer database, administrator/migration/maintenance, web-session,
  support/email, and AI authorities outside their owning service.

ADR 0063 records the Git-free build decision; ADR 0064 records service-specific configuration and
credential projections. The credential-free artifact records the failed and corrected boundaries,
exact image identities, source hashes, runtime assertions, cleanup, and limitations:
`artifacts/container-image-runtime-verification-2026-07-30.json`.
