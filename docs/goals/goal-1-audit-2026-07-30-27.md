## Requirement gap narrowed locally

Audit 26 left all candidate-image scanning and SBOM generation unverified. The first bounded local
candidate attempt correctly failed: the then-current API image contained thirteen fixed High and
three fixed Critical findings across its Debian packages and globally installed npm toolchain. That
failure was treated as a product-image blocker, not waived as scanner or build noise.

The remediation:

- advances every application build and runtime stage from Node 24.14.0 to the official
  `node:24.18.0-bookworm-slim` multi-platform manifest-list digest;
- removes npm, Corepack, and their command shims from every final runtime stage before application
  files are copied;
- statically prevents a Node 24 Active LTS regression below 24.18.0 or a distribution-tag ambiguity;
- statically requires the exact runtime toolchain-removal command;
- gives frozen install and deploy steps one exact locked pnpm-store cache mount so transient
  registry failures preserve already verified package content without copying the cache into runtime
  images;
- pins the latest immutable Trivy action release at its full v0.36.0 commit and explicitly selects
  immutable scanner v0.72.0;
- rejects mutable/default and March 2026 incident-affected scanner identities; and
- extracts the OCI archive before scanning while retaining checksums and hosted attestations over
  the original archive.

ADR 0066 records the decision and the incident-aware scanner boundary.
