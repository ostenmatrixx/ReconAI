## Requirement gap closed locally

The real post-patch OIDC exercise in audit 14 exposed a synthetic authorization callback in the
Next.js development terminal. That output was not retained in repository evidence, but it prompted a
review of the deployable Nginx boundary. Without an explicit format, Nginx's default combined access
log includes the complete request target and query string, so an OIDC or provider OAuth callback
could place short-lived authorization credentials in edge logs.

No staging or production edge exists and no customer or production credential was exposed. The
source configuration risk is now closed locally:

- the reference edge explicitly emits JSON with only timestamp, generated request ID, connected
  client address, method, normalized query-free path, protocol, status, response bytes, and request
  duration;
- query strings, referrer, cookie, authorization, user-agent, and default combined-log fields are
  absent;
- `pnpm edge:check` rejects `$request`, `$request_uri`, `$args`, `$query_string`, referrer, cookie,
  authorization, and combined access logs, and its negative self-tests prove those regressions are
  detected;
- a fresh isolated build from the exact previously evidenced Nginx 1.30.4 source commit parsed the
  canonical configuration;
- the live verifier sent a synthetic callback-shaped request containing `code` and `state`, parsed
  thirteen exact JSON log entries, recorded only `/api/edge-probe`, and found neither synthetic
  value nor query parameter in the log; and
- the same run retained the prior forwarding-chain overwrite, BFF/API routing split, two-Fastify
  distribution, body ceiling, security-header, version-hiding, and 100-request outer-budget
  assertions.

The isolated Nginx source/build directory was moved to the workstation Trash after the verifier
stopped Nginx and its upstreams. It is recoverable until Trash is emptied.

No tenant authority, database behavior, reconciliation rule, money handling, provider scope,
source-system write authority, or AI authority changes.
